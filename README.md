# La date

Une mini application web qui affiche le **jour de l'année** (de 1 à 365, ou 366 les années bissextiles) avec un dégradé de couleurs animé.

## Fichiers

- `index.html` : la page et ses styles (animation de couleur)
- `script.js` : calcule et affiche le jour de l'année
- `README.md` : ce fichier

## Utilisation

Ouvrez simplement `index.html` dans votre navigateur (double-clic). Aucune installation n'est nécessaire.

## Fonctionnement

Le script compte les jours écoulés depuis le 1er janvier de l'année en cours, affiche ce numéro en grand, et la date complète en français en dessous. L'affichage se met à jour automatiquement chaque minute.
